## Handoff rule

Launchpad must independently approve source, verify registry access and artifact
evidence, render deployment inputs, supply runtime secrets, exercise live
conditions, measure resources, certify seat counts, reclaim with zero residue,
and promote. A factory handoff accelerates those gates; it never satisfies them.
