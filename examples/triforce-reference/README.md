# Triforce golden reference

This example records the qualities the starter must preserve without coupling a
generated demo to Triforce services or industry copy.

- Red Hat × Intel lockup and dark, presentation-first visual system.
- A cold open that establishes a recognizable operating reality.
- Stakes before architecture; architecture before live proof.
- Progressive reveals instead of dense static slides.
- Honest performance, cost, and limitation framing.
- A measured payoff followed by adjacent journeys.
- Full-screen delivery, act progress, deliberate transitions, and a final CTA.

The story map in `demo.config.ts` is the narrative comparison point. The
Playwright screenshots in the canonical template are the visual regression
point at presentation, laptop, and narrow rehearsal sizes.
